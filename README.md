# PokeCard Market

Telegram marketplace for collectors and resellers to buy/sell Pokémon cards; sellers list items and pay a per-sale on-chain fee, owner notified via Telegram and email.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
